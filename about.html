About DevWorKit (DWK)

DevWorKit은 직장인과 소프트웨어 개발자의 일상적인 반복 작업과 야근을 줄여주기 위해 제작된 무료 웹 생산성 툴킷 세트입니다. 텍스트에서 필요한 값을 뽑고, 글자수와 바이트를 확인하고, 문서나 코드를 비교하고, 데이터를 변환하는 작업처럼 업무 중 자주 반복되는 일들을 도구 13종과 그에 맞는 실무 가이드로 정리했습니다.

🎯 만든 이유와 방향

이런 작업은 대부분 "그때그때 검색해서 아무 사이트나 열어 해결하는" 식으로 처리됩니다. 그러면 사이트마다 결과가 미묘하게 다르거나, 회사 문서를 낯선 서버에 올려야 하거나, 한글 바이트처럼 국내 서식에만 필요한 기준을 지원하지 않는 경우가 생깁니다. DevWorKit은 한국 업무 환경에서 자주 필요한 기능을 한곳에 모으고, 결과가 왜 그렇게 나오는지까지 가이드로 설명하는 것을 목표로 합니다.

📌 운영 원칙

  • 입력한 데이터는 서버로 보내지 않습니다. 모든 도구는 사용자의 브라우저 안에서만 동작합니다. (자세한 내용은 개인정보처리방침)
  • 결과만 주지 않고 이유를 설명합니다. 각 도구마다 동작 원리와 흔한 실수를 다룬 실무 가이드를 함께 제공합니다.
  • 기준은 공개 표준과 공식 문서입니다. 가이드는 RFC, W3C(WCAG), ECMAScript 등 공개된 규격을 바탕으로 작성하며, 확인이 어려운 수치나 과장된 표현은 쓰지 않으려고 합니다.
  • 잘못된 내용은 고칩니다. 오류나 오탈자, 도구의 오동작을 제보해 주시면 확인 후 수정하고 아래 업데이트 내역에 남깁니다.

🧰 도구와 가이드

도구하는 일가이드
문자열 추출기
STRGET		긴 텍스트에서 이메일·전화번호·IP·날짜를 정규식으로 추출해 엑셀 표로 복사가이드
글자수 & 바이트 계산기
COUNTER		공백 포함/제외 글자수와 EUC-KR·UTF-8 바이트 계산가이드
텍스트 & 코드 비교기
STRCMP		두 텍스트의 차이를 라인·단어 단위로 비교하고 일치율 계산가이드
마크다운 실시간 에디터
MARKDOWN		수식(LaTeX)·다이어그램(Mermaid)·표를 실시간 렌더링하고 HTML로 추출가이드
폴더 구조 엑셀 변환기
FSEE		폴더·ZIP의 계층 구조를 트리 형태의 엑셀 문서로 변환가이드
Base64 & URL 변환기
CODER		한글이 깨지지 않는 Base64·URL·HTML 엔티티 인코딩/디코딩가이드
코드 뷰티파이어 & 뷰어
BEAUTIFY		HTML·CSS·JavaScript·PowerShell 정렬과 압축, 웹 화면 미리보기가이드
JSON 포맷터 & 검사기
JSON		JSON 정렬·압축·구문 오류 위치 확인, TypeScript 인터페이스 변환가이드
타임스탬프 변환기
TIME		Unix 타임스탬프(초/밀리초)와 KST·UTC·ISO 8601 상호 변환가이드
UUID & 해시 생성기
HASH		UUID v4 생성과 SHA-256/512/1 해시 계산가이드
QR 코드 생성기
QR		QR 코드 생성(중앙 로고 지원)과 이미지 스캔가이드
크론탭 주기 생성기
CRON		크론 표현식 생성, 한국어 해석, 다음 실행 시각 미리보기가이드
웹 색상 스튜디오
COLOR		텍스트·배경색의 WCAG 2.1 명도 대비비 검증가이드

📝 업데이트 내역

  • 2026.10 실무 가이드를 도구 13종 전체로 확대하고, 각 도구 페이지에서 해당 가이드로 바로 이동할 수 있게 연결했습니다.
  • 2026.10 코드 뷰티파이어에 PowerShell(.ps1) 정렬·압축 모드를 추가했습니다. 한국어 Windows에서 한글이 깨지지 않도록 .ps1 다운로드 시 UTF-8 BOM을 붙이고, 파일 불러오기 시 UTF-8·UTF-16·EUC-KR 인코딩을 자동 판별합니다.
  • 2026.10 코드 뷰티파이어의 압축 기능을 개선했습니다. 이전 버전은 문자열 안의 //(예: URL)를 주석으로 오인해 코드를 훼손할 수 있었고, 현재는 문자열·정규식·템플릿 리터럴을 보호한 채 주석과 공백만 제거합니다.
  • 2026.10 기존 가이드의 오탈자, 서식 오류, 부정확한 설명(해시·시간·색상·JSON 가이드 등)을 정정했습니다.
