Base64 인코딩 원리와 실무 한글 깨짐 해결법

1. Base64 인코딩이란 무엇인가?

Base64는 8비트 이진 데이터(Binary Data)를 공통으로 인쇄 가능한 64개의 ASCII 문자셋([A-Z, a-z, 0-9, +, /])으로 변환하는 대표적인 바이너리-텍스트 인코딩 방식입니다. 주로 네트워크 프로토콜(HTTP, 이메일 MIME) 환경에서 데이터의 유실이나 제어 문자로 인한 깨짐 현상을 방지하기 위해 사용됩니다.

2. 자바스크립트 실무에서 한글(UTF-8) 깨짐이 발생하는 이유

브라우저 기본 내장 API인 window.btoa() 함수는 문자 1개당 1바이트(ASCII) 기준 데이터만 처리하도록 설계되어 있습니다. 2바이트 이상을 사용하는 UTF-8 한글 문자열을 전달할 경우 즉시 InvalidCharacterError(DOMException) 예외가 발생하거나 디코딩 시 글자가 깨지는 현상이 발생합니다.

// 안전한 UTF-8 문자열 Base64 변환 함수 예시 function safeBase64Encode(str) { return btoa(encodeURIComponent(str).replace(/%([0-9A-F]{2})/g, (match, p1) => { return String.fromCharCode('0x' + p1); })); }

3. 무료 온라인 변환 도구 활용

복잡한 코드 작성 없이 안전하게 브라우저 환경에서 즉시 텍스트 및 URL, Base64 데이터를 상호 변환할 수 있습니다.
