BEAUTIFY

코드 뷰티파이어(Beautifier)의 동작 원리와 들여쓰기 표준 가이드

1. 코드 뷰티파이(Code Beautifying)란?

코드 뷰티파이어는 공백, 줄바꿈, 괄호 위치 등이 엉망이거나 한 줄로 압축(Minify)된 소스 코드를 구문 트리(AST) 분석을 통해 일관된 표준 들여쓰기 규칙으로 재정렬해 주는 도구입니다.

2. 들여쓰기 2칸(Space 2) vs 4칸(Space 4) 표준

프로그래밍 언어와 프레임워크마다 권장하는 표준 스타일 가이드가 다릅니다.

  • 2칸 들여쓰기: HTML, CSS, JavaScript(React, Vue, Node.js), JSON 등 중첩 깊이가 깊은 프론트엔드 환경에서 주로 사용됩니다.
  • 4칸 들여쓰기: Python(PEP8), Java, C/C++ 등 구조적 블록 구분이 명확해야 하는 백엔드 환경에서 표준으로 권장됩니다.

3. AST 기반 포맷팅 처리 원리 예시

// 엉망인 원본 코드
function test(a,b){if(a>0){return a+b;}return 0;}

// 뷰티파이어를 거친 표준 정렬 결과
function test(a, b) {
    if (a > 0) {
        return a + b;
    }
    return 0;
}

4. DevWorKit 온라인 코드 뷰티파이어 & 웹 뷰어

별도의 확장 프로그램 설치 없이 브라우저에서 HTML, CSS, JavaScript 코드를 즉시 2칸/4칸/Tab 단위로 정렬하고, 작성된 HTML 화면을 실시간으로 미리 볼 수 있습니다.
