리눅스 크론탭(Crontab) 문법 완벽 정복과 실무 스케줄러 가이드

작성일: 2026-08-25 | 카테고리: 서버/자동화 | DevWorKit 기술팀

리눅스 환경에서 백업, 배치 작업, 데이터 동기화 등을 자동화할 때 가장 기본적으로 사용하는 도구가 바로 cron(crontab)입니다. 하지만 5개 필드의 의미와 특수 기호 규칙을 헷갈려 잘못 설정하면 서버 장애로 이어질 수 있습니다. 이번 가이드에서는 크론탭 문법을 완벽히 정리합니다.

⏱️ 복잡한 크론탭 주기를 한글로 바로 확인하고 싶으신가요?

클릭만으로 크론식을 생성하고 다음 실행 일정을 미리 계산해보세요.

1. 크론탭 5대 필드 기본 구조

표준 리눅스 크론탭은 공백으로 구분된 5개의 시간 필드로 구성됩니다.

* * * * *

│ │ │ │ │

│ │ │ │ └─ 요일 (0 - 6, 0=일요일, 6=토요일)

│ │ │ └─── 월 (1 - 12)

│ │ └───── 일 (1 - 31)

│ └─────── 시 (0 - 23)

└───────── 분 (0 - 59)

2. 반드시 알아야 할 4대 특수 기호

  • * (와일드카드): 해당 시간 단위의 모든 값을 의미합니다. (예: * * * * * = 매 1분마다 실행)
  • / (주기): 특정 간격마다 반복합니다. (예: */10 * * * * = 10분마다 실행)
  • , (목록): 여러 개의 특정 값을 지정합니다. (예: 0 9,18 * * * = 매일 9시와 18시 정각에 실행)
  • - (범위): 연속된 범위를 지정합니다. (예: 0 9-18 * * 1-5 = 평일 9시부터 18시까지 매시 정각)

3. 실무에서 가장 많이 쓰는 크론탭 예제 모음

  • 매일 자정 DB 백업: 0 0 * * * /scripts/backup.sh
  • 평일 업무시간(09~18시) 30분마다 헬스체크: */30 9-18 * * 1-5 /scripts/check.sh
  • 매월 1일 새벽 2시 로그 압축: 0 2 1 * * /scripts/log_rotate.sh

4. 크론탭 등록 시 주의할 팁

크론 데몬은 사용자 쉘 환경변수(PATH 등)를 기본적으로 로드하지 않습니다. 따라서 스크립트 실행 시 /usr/bin/python3 처럼 절대 경로를 지정하거나 스크립트 상단에 환경변수를 명시해야 경로 오류를 방지할 수 있습니다.
