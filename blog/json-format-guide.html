JSON 유효성 검사와 구조적 데이터 파싱 팁

1. JSON(JavaScript Object Notation)이란?

JSON은 경량의 데이터 교환 형식으로, 사람이 읽고 쓰기 쉬우며 기계가 분석하고 생성하기 용이합니다. RESTful API 통신, 설정 파일(`.json`), NoSQL 데이터베이스 등 최신 웹 애플리케이션 전반에서 표준 규격으로 채택되어 사용됩니다.

2. 실무에서 가장 흔히 발생하는 JSON 문법 오류 Top 3

서버 통신 시 JSON.parse()에서 SyntaxError: Unexpected token 예외가 발생하는 대표적인 원인은 다음과 같습니다:

① 마지막 쉼표(Trailing Comma): 객체나 배열의 마지막 요소 뒤에 불필요한 쉼표(,)가 남아 있는 경우.

② 따옴표 규칙 위반: JSON 표준 규격에서는 키(Key)와 문자열 값에 반드시 큰따옴표(")만을 허용하며, 작은따옴표(')는 문법 오류로 처리됩니다.

③ 이스케이프 누락: 문자열 내부에 큰따옴표나 백슬래시가 포함될 때 역슬래시(\") 처리가 누락된 경우.

// 안전한 JSON 파싱 트라이-캐치 패턴 예시 function parseJSONSafely(jsonString) { try { return { success: true, data: JSON.parse(jsonString) }; } catch (error) { return { success: false, error: error.message }; } }
