마크다운은 간단한 텍스트 기호만으로 웹 문서를 구조화할 수 있는 강력한 경량 마크업 언어입니다. 본 문서에서는 기초 문법부터 수식 및 다이어그램까지 실무에서 사용하는 모든 문법을 정리합니다.

1. 헤딩과 텍스트 스타일

# H1 대제목 ## H2 중제목 ### H3 소제목 **굵은 글씨**, *기울임 글씨*, ~~취소선~~, ==형광펜 강조==

2. 리스트 및 체크리스트 (Task List)

- 일반 글머리 기호 1 - 일반 글머리 기호 2 1. 순서가 있는 번호 목록 2. 두 번째 순서 - [x] 완료된 작업 항목 - [ ] 아직 진행 중인 작업 항목

3. 링크, 이미지 및 인용구
