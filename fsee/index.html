FSEE 폴더 구조 엑셀 추출기

폴더내 파일명을 보기 쉽게 엑셀로 추출하는 사이트입니다.

폴더 또는 ZIP내의 파일명을 엑셀 문서로 추출할 수 있습니다.

디렉토리 구조 분석 및 추출 방법 안내:

  1. 중앙의 회색 점선 영역을 클릭하거나 하단의 전용 버튼을 활용하여 파일/폴더 데이터를 로드합니다.
  2. 폴더 선택 기능을 이용하면 웹 브라우저의 내부 제약을 우회하여 완벽한 하위 트리를 스캔합니다.
  3. 압축 파일 내부 문서 구조가 필요한 경우 파일 / ZIP 선택을 통해 별도의 압축 해제 없이 즉시 목록을 추출할 수 있습니다.
  4. 스캔이 완료되면 각 하위 폴더별 계층 구조가 시각적으로 정돈된 인덴트 분리형 엑셀(.xlsx) 파일이 자동으로 생성되어 다운로드됩니다.
