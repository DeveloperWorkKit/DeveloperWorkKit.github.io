FSEE

폴더 구조 엑셀 변환기

로컬 폴더 트리나 ZIP 압축 파일 내부의 디렉터리 경로를 스캔하여 계층별 인덴트가 적용된 스프레드시트(.xlsx) 파일로 즉시 추출합니다.

디렉토리 구조 분석 및 추출 방법 안내:
  1. 중앙 점선 영역을 클릭하거나 하단 버튼을 통해 분석할 폴더 또는 압축 파일을 지정합니다.
  2. [폴더 선택] 기능을 이용하면 크롬/엣지 브라우저의 파일 시스템 API를 통해 방대한 하위 디렉터리를 고속 스캔합니다.
  3. 압축 파일 내부 구조가 필요한 경우 [파일 / ZIP 선택]을 통해 별도의 압축 해제 없이 파일 목록을 즉시 추출합니다.
  4. 스캔이 완료되면 폴더 깊이(Depth)별로 정돈된 엑셀(.xlsx) 파일이 자동으로 생성되어 다운로드됩니다.
📁 여기를 클릭하거나 폴더/ZIP 파일을 드래그하여 놓으세요 로컬 환경에서만 안전하게 고속으로 파싱됩니다
선택 대기중

디렉터리 파일 트리 엑셀 변환의 실무 필요성과 원리

DevWorKit 폴더 구조 엑셀 변환기(FSEE)는 사내 프로젝트 산출물 정리, 서버 인프라 데이터 백업 검증, 외주 개발 납품 파일 검수 등 복잡한 폴더 계층 구조를 직관적인 표(Spreadsheet) 형태로 보고해야 하는 실무자를 위한 자동화 유틸리티입니다.

1. 계층별 시각적 인덴트(Tree Indent)와 폴더 우선 정렬

일반적인 단순 알파벳 순서 정렬은 폴더와 파일이 뒤섞여 가독성을 떨어뜨립니다. 본 도구는 탐색기(Explorer) 표준 방식을 적용하여 폴더(Directory)를 파일보다 항상 상단에 우선 배치하고, 그 아래에 파일들을 가나다순으로 정렬합니다.

  • 차수별 컬럼 분리: 상위 폴더부터 하위 디렉터리까지 1차 폴더명, 2차 폴더명, 3차 폴더명 컬럼으로 분리 배치하여 피벗 테이블 및 필터 적용이 용이합니다.
  • 트리 기호(└) 자동 적용: 상위 폴더가 전환되는 첫 위치에만 └ 시각 기호를 조합하고 중복 상위 폴더는 공란으로 비워 직관적인 트리 뷰를 완성합니다.
  • 메타데이터 분리: 파일명뿐만 아니라 확장자(Extension)와 전체 절대경로를 별도 열로 추출하여 특정 확장자(.pdf, .java, .xlsx 등)만 선별 필터링할 수 있습니다.

2. ZIP 압축 파일의 인메모리(In-Memory) 스트리밍 파싱

수 기가바이트(GB)에 달하는 대용량 ZIP 파일의 목록만 확인하고 싶을 때, 압축을 푸는 과정은 상당한 디스크 용량과 시간을 소모합니다. 본 도구는 JSZip 라이브러리를 통해 압축 해제 없이 헤더 청크만 메모리상에서 직접 탐색하므로 1초 내에 내부 파일 트리를 엑셀로 추출합니다.

3. 자주 묻는 질문 (FAQ)

Q. 회사 기밀 폴더나 소스코드를 선택해도 외부 서버로 파일이 업로드되지 않나요?
A. 전혀 업로드되지 않습니다. DevWorKit은 모던 웹 표준인 showDirectoryPicker 및 로컬 FileReader API를 사용하여 사용자의 웹 브라우저 내부 메모리에서만 파일 목록을 읽고 엑셀을 빌드합니다. 파일의 실제 내용(Content)은 일체 열람하거나 전송하지 않으며, 오직 경로와 파일명만 처리됩니다.
Q. 수만 개 이상의 파일이 들어 있는 대형 폴더도 처리가 가능한가요?
A. 네, 처리 가능합니다. [폴더 선택] 버튼 클릭 시 비동기 제너레이터(Async Iterator) 패턴을 적용하여 브라우저 멈춤 현상(Freezing) 없이 수만 개의 파일 경로를 순차적으로 스캔하고 SheetJS 엔진을 통해 엑셀 바이너리를 생성합니다.
