글자수·바이트 계산 기준 완벽 가이드: EUC-KR vs UTF-8 차이와 제출용 서식 실무

1. 글자수와 바이트 수는 왜 서로 다른 숫자인가

글자수는 사람이 눈으로 세는 문자의 개수이고, 바이트 수는 그 문자를 컴퓨터가 특정 인코딩으로 저장할 때 차지하는 메모리 크기입니다. 영문과 숫자는 어떤 인코딩에서든 1글자가 1바이트이지만, 한글은 인코딩 방식에 따라 차지하는 바이트가 달라지기 때문에 같은 문장도 "몇 바이트인가"는 기준 인코딩 없이는 답할 수 없습니다.

문자 종류EUC-KR (CP949)UTF-8
한글 완성형 (가, 힣 등)2바이트3바이트
영문 · 숫자 · 공백1바이트1바이트
줄바꿈 (LF / CRLF)1바이트 / 2바이트1바이트 / 2바이트
이모지 (😀 등)표현 불가4바이트

엄밀히 말해 EUC-KR 완성형은 2,350자만 수록하며, 현대 한글 11,172자를 모두 2바이트로 표현하도록 확장한 것이 CP949(MS949)입니다. 국내 레거시 시스템의 "EUC-KR 기준 바이트"는 대부분 이 확장 규격을 가리킵니다.

2. 공공기관·레거시 시스템에서 바이트 제한이 쓰이는 이유

채용 사이트, 행정 서식, 정부 지원사업 신청서처럼 오래된 시스템은 입력 항목을 데이터베이스 컬럼의 바이트 길이로 제한하는 경우가 많습니다. 예를 들어 Oracle의 VARCHAR2(1000 BYTE) 컬럼은 글자 수가 아니라 바이트 수를 기준으로 입력을 제한합니다.

같은 1,000바이트 제한이라도 EUC-KR 환경에서는 한글 약 500자, UTF-8 환경에서는 한글 약 333자까지만 입력할 수 있습니다. 시스템이 어느 인코딩을 쓰는지 알 수 없다면, 더 엄격한 UTF-8 기준(한글 3바이트)으로 분량을 맞춰 두는 편이 초과 오류를 피하는 안전한 방법입니다.

3. 자바스크립트로 바이트 수 계산하기

String.length는 바이트가 아니라 UTF-16 코드 유닛 개수를 반환하므로 바이트 계산에는 쓸 수 없습니다. 브라우저에 내장된 TextEncoder를 사용하면 UTF-8 바이트 수를 정확히 구할 수 있고, EUC-KR 바이트는 ASCII 여부로 근사 계산합니다.

// UTF-8 바이트 수 (브라우저 내장 TextEncoder 활용) function utf8Bytes(str) { return new TextEncoder().encode(str).length; } // EUC-KR(CP949) 근사 바이트 수: ASCII는 1바이트, 그 외 문자는 2바이트로 계산 function euckrBytes(str) { let bytes = 0; for (const ch of str) { bytes += ch.charCodeAt(0) <= 0x7f ? 1 : 2; } return bytes; }

EUC-KR 계산은 근사치입니다. 이모지처럼 CP949에 없는 문자는 실제로는 저장 자체가 불가능하며, 시스템에 따라 물음표(?)로 치환되거나 오류가 발생합니다.

4. 공백과 줄바꿈 처리에서 생기는 차이

글자수 기준에는 "공백 포함"과 "공백 제외" 두 가지가 있고, 제출처가 어느 쪽인지 명시하지 않은 경우가 많습니다. 문장 사이의 띄어쓰기만으로도 수십 자 차이가 나므로 두 값을 모두 확인해 두어야 합니다.

줄바꿈도 주의해야 합니다. 자바스크립트의 textarea.value는 줄바꿈을 LF 1글자로 보지만, HTML 폼은 제출 시 줄바꿈을 CRLF(2글자)로 정규화합니다. 그래서 화면의 글자수 표시와 서버가 받은 길이가 줄 수만큼 어긋나는 일이 생깁니다. 문단 구분이 많은 글일수록 분량에 여유를 두고 작성하세요.

5. 제출 전 체크리스트

  • 공고문에서 기준 단위(글자수인지 바이트인지)와 공백 포함 여부를 먼저 확인합니다.
  • 바이트 기준이라면 EUC-KR과 UTF-8 값을 모두 확인하고, 더 큰 값이 제한 안에 들어오도록 맞춥니다.
  • 줄바꿈 때문에 늘어날 수 있는 분량을 감안해 제한의 90~95% 선에서 마무리합니다.
  • 이모지, 특수기호, 서로 다른 문서 프로그램에서 복사된 숨은 서식 문자는 가급적 제거합니다.
  • 워드프로세서마다 글자수 산정 방식이 다르므로, 최종 확인은 실제 제출 화면의 입력창에서 한 번 더 합니다.
