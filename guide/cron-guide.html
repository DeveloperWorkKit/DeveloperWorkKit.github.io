리눅스 크론탭(Crontab) 문법 완벽 정복과 실무 스케줄러 가이드

1. 크론탭(Cron)과 스케줄러란?

리눅스 환경에서 백업, 배치 작업, 데이터 동기화 등을 주기적으로 자동화할 때 사용하는 표준 작업 스케줄러 도구입니다. 5개의 시간 필드로 구성된 크론 표현식을 통해 원하는 실행 주기를 정밀하게 정의합니다.

2. 크론탭 5대 필드 기본 구조

표준 리눅스 크론탭은 공백으로 구분된 5개의 시간 단위 필드를 순서대로 파싱합니다:

* * * * *
│ │ │ │ │
│ │ │ │ └─ 요일 (0 - 6, 0=일요일, 6=토요일)
│ │ │ └─── 월 (1 - 12)
│ │ └───── 일 (1 - 31)
│ └─────── 시 (0 - 23)
└───────── 분 (0 - 59)

3. 반드시 알아야 할 4대 특수 기호

① * (와일드카드): 해당 시간 단위의 모든 값을 의미합니다. (예: * * * * * = 매 1분마다 실행)

② / (주기): 특정 간격마다 반복 실행합니다. (예: */10 * * * * = 10분마다 실행)

③ , (목록): 여러 개의 특정 값을 지정합니다. (예: 0 9,18 * * * = 매일 9시와 18시 정각 실행)

④ - (범위): 연속된 구간 동안 실행합니다. (예: 0 9-18 * * 1-5 = 평일 9시부터 18시까지 매시 정각)

4. 무료 온라인 크론탭 생성기 & 한글 번역기 활용

복잡하고 헷갈리는 크론 표현식을 클릭만으로 생성하고, 자연어 한국어 해석과 다음 5회 실행 일정을 즉시 확인할 수 있습니다.
