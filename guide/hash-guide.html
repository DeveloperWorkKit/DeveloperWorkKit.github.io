단방향 암호화 해시(SHA-256)와 UUID v4 원리 정리

1. 단방향 해시 함수(SHA-256)란?

해시 함수는 임의의 길이를 가진 입력 데이터를 고정된 길이의 16진수 문자열로 변환하는 알고리즘입니다. SHA-256은 256비트(64자리 16진수) 해시값을 출력하며, 결과값으로 원래 평문을 역산하는 것이 수학적으로 불가능하여 비밀번호 검증 및 데이터 무결성 체크에 표준으로 사용됩니다.

2. 고유 식별자 UUID v4의 무작위 생성 원리

UUID(Universally Unique Identifier)는 중앙 통제 시스템 없이도 고유성을 보장하는 128비트 식별자입니다. 버전 4(UUID v4)는 암호학적으로 안전한 의사 난수(CSPRNG)를 기반으로 생성되며, 중복될 확률이 사실상 0에 수렴하여 분산 시스템의 Primary Key로 널리 사용됩니다.

// 웹 표준 Web Crypto API를 사용한 안전한 SHA-256 해시 생성 예제 async function generateSHA256(message) { const msgBuffer = new TextEncoder().encode(message); const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer); const hashArray = Array.from(new Uint8Array(hashBuffer)); return hashArray.map(b => b.toString(16).padStart(2, '0')).join(''); }
