DWK GUIDE

실무 기술 가이드

도구별 동작 원리와 실무 활용 노하우를 정리한 DevWorKit 기술 가이드 모음

🔍
STRGET

정규표현식(Regex)을 이용한 이메일·전화번호 추출 가이드

비정형 텍스트 뭉치에서 원하는 패턴의 문자열만 정규식으로 정확히 파싱하는 실전 패턴을 설명합니다.
COUNTER

글자수·바이트 계산 기준 완벽 가이드: EUC-KR vs UTF-8 차이와 제출용 서식 실무

EUC-KR과 UTF-8의 한글 바이트 차이, 공백·줄바꿈 처리 기준, 제출 전 체크리스트를 정리합니다.
STRCMP

텍스트·코드 비교(Diff) 알고리즘 원리와 실무 활용 가이드

LCS 기반 Diff 원리와 라인·단어 단위 비교의 차이, 공백·줄바꿈으로 생기는 가짜 차이를 정리합니다.
MARKDOWN

마크다운(Markdown) 기초부터 확장 문법까지 완벽 가이드

기본 서식, 체크리스트, 표(Table)부터 LaTeX 수학 수식과 Mermaid 다이어그램까지 마크다운 실전 활용법을 총정리합니다.
FSEE

폴더 구조를 엑셀 트리 문서로 변환하는 원리와 실무 활용 가이드

디렉터리 트리 평탄화 원리와 ZIP 구조 읽기, 인수인계·감사 자료용 엑셀 문서화 팁을 설명합니다.
CODER

Base64 인코딩 원리와 실무 한글 깨짐 해결법

Base64의 내부 동작 원리와 웹 통신 중 발생하는 UTF-8 한글 깨짐 문제의 원인 및 해결 코드를 정리합니다.
BEAUTIFY

코드 뷰티파이어의 동작 원리와 들여쓰기 표준 가이드

엉킨 소스코드를 깔끔하게 정돈하는 AST 파싱 원리와 HTML/JS 들여쓰기(2칸 vs 4칸) 표준 규칙을 정리합니다.
JSON

JSON 유효성 검사와 구조적 데이터 파싱 팁

대용량 JSON 트러블슈팅과 구문 오류(Syntax Error)를 빠르게 진단하는 실무 노하우를 알아봅니다.
TIME

Unix Epoch Timestamp 개념과 시간대 변환 가이드

10자리 초와 13자리 밀리초의 차이점, 그리고 KST/UTC 시간대 상호 변환 시 주의사항을 정리합니다.
HASH

단방향 암호화 해시(SHA-256)와 UUID v4 원리 정리

데이터 무결성 검증을 위한 SHA-256 해시 알고리즘과 고유 식별자 생성을 위한 UUID v4 원리를 설명합니다.
QR

QR 코드 생성 원리와 오류 정정 레벨, 인쇄 품질 실무 가이드

오류 정정 레벨(L/M/Q/H)과 로고 삽입, 데이터 용량, 인쇄 크기·여백 기준을 정리합니다.
CRON

리눅스 크론탭 문법 완벽 정복과 실무 스케줄러 가이드

5개 필드(분 시 일 월 요일)의 동작 규칙과 특수 문자(*, /, -, ,) 활용법, 실무 에러 방어 팁을 정리합니다.
COLOR

웹 접근성(WCAG 2.1) 명도 대비비 기준과 실무 UI 배색 가이드

W3C WCAG 2.1 AA/AAA 기준 명도 대비비 계산 공식과 주 텍스트, 본문, 배경색 3채널의 실무 배색 원리를 정리합니다.
