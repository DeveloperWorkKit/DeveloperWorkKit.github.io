1. 헤딩과 텍스트 스타일

2. 리스트 및 체크리스트 (Task List)

순서가 없거나 있는 목록 및 체크박스 할 일 목록을 작성합니다.

- 일반 글머리 기호 1 - 일반 글머리 기호 2 1. 순서가 있는 번호 목록 2. 두 번째 순서 - [x] 완료된 작업 항목 - [ ] 아직 진행 중인 작업 항목

3. 링크, 이미지 및 인용구

외부 링크, 이미지 임베드, GitHub 스타일의 알림 콜아웃을 구성합니다.

[구글 바로가기](https://google.com) ![이미지 대체 텍스트](https://example.com/image.png) > 일반 인용구 텍스트입니다. > [!NOTE] > 여기에 강조할 공지사항이나 핵심 안내 텍스트를 작성하세요.

5. LaTeX 수학 수식

KaTeX 수식 렌더러를 통해 인라인 및 블록 수식을 표현합니다.

인라인 수식: $E = mc^2$ 블록 수식: $$ \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} $$

6. Mermaid 플로우차트 다이어그램

텍스트 코드로 벡터 다이어그램과 순서도를 즉시 렌더링합니다.

```mermaid graph TD A[시작] --> B{조건 분기} B -->|Yes| C[성공] B -->|No| D[재시도] ```
