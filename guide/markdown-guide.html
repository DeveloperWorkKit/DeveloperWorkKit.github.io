마크다운(Markdown) 실전 문법 치트키 & 작성 가이드

1. 기본 텍스트 서식 및 헤딩

문서의 구조를 잡고 텍스트를 강조하는 가장 기본적인 마크다운 문법입니다.

# H1 제목 (가장 큰 대제목) ## H2 중간 제목 ### H3 소제목 **굵은 글씨 (Bold)** *기울임 글씨 (Italic)* ~~취소선 (Strikethrough)~~ ==형광펜 강조 (Mark)== `인라인 코드 (Code)`

2. 리스트 및 인터랙티브 체크리스트

글머리 기호 목록과 우측 뷰어에서 직접 클릭해 토글할 수 있는 체크박스 문법입니다.

- 일반 글머리 기호 항목 1 - 하위 들여쓰기 항목 A - 일반 글머리 기호 항목 2 1. 순서가 있는 번호 목록 1 2. 순서가 있는 번호 목록 2 - [x] 완료된 작업 항목 - [ ] 미완료된 작업 항목

3. 링크, 이미지 및 인용구 (Callout)

외부 링크, 이미지 임베드 및 GitHub 스타일의 알림 박스(Callout) 작성법입니다.

[DevWorKit 바로가기](https://developerworkkit.github.io) ![대체 텍스트](https://example.com/image.png) > 일반 인용구 텍스트 영역입니다. > [!NOTE] > 중요 공지나 팁을 시각적으로 강조하는 알림 콜아웃 박스입니다.

4. 표(Table) 및 접기/펼치기 (Details)

파이프 기호(|)를 이용한 표 정렬과 긴 본문을 숨길 수 있는 아코디언 태그입니다.

| 기능명 | 지원 여부 | 단축키 | | :--- | :---: | :---: | | 실시간 렌더링 | ✅ 지원 | Ctrl+S | | HTML 변환 | ✅ 지원 | Ctrl+C |
▶ 클릭하여 상세 내용 접기/펼치기 여기에 숨겨둘 상세 설명이나 긴 소스코드를 자유롭게 작성합니다.

5. 고급 확장: LaTeX 수학 수식과 Mermaid 다이어그램

복잡한 수식과 순서도(Flowchart)를 텍스트 코드로 즉시 렌더링합니다.

인라인 수식: $E = mc^2$ 블록 수식: $$ \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} $$ ```mermaid graph TD A[마크다운 작성] --> B{실시간 파서} B --> C[KaTeX 수식] B --> D[Mermaid 다이어그램] C --> E[HTML 뷰어] D --> E ```
