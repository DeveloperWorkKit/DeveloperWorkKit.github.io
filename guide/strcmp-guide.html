텍스트·코드 비교(Diff) 알고리즘 원리와 실무 활용 가이드

1. Diff(텍스트 비교)란 무엇인가

Diff는 두 텍스트 사이에서 무엇이 추가되고 무엇이 삭제되었는지를 최소한의 편집 목록으로 계산하는 기법입니다. 핵심은 두 텍스트가 공통으로 가진 가장 긴 부분 수열(LCS, Longest Common Subsequence)을 찾는 것이며, 여기에 포함되지 않는 부분이 "변경된 부분"이 됩니다.

Git이 기본으로 사용하는 Myers 알고리즘(1986)을 비롯해 대부분의 비교 도구는 이 LCS 문제를 효율적으로 푸는 방식에 기반합니다. 문서 개정본 대조, 코드 리뷰, 설정 파일 변경 확인처럼 "무엇이 바뀌었는지"가 중요한 모든 작업의 출발점입니다.

2. 라인·단어·문자 단위 비교의 차이

같은 두 텍스트라도 비교 단위를 무엇으로 잡느냐에 따라 결과가 크게 달라집니다.

비교 단위적합한 문서특징
라인(줄)소스코드, 설정 파일, 로그줄 하나라도 바뀌면 줄 전체가 변경으로 표시됩니다. 구조가 줄 단위로 명확한 문서에 빠르고 읽기 쉽습니다.
단어계약서, 약관, 공문 등 긴 문장한 줄 안에서 바뀐 단어만 짚어줍니다. 조사나 숫자 하나가 의미를 바꾸는 문서에 유리합니다.
문자짧은 문자열, 오탈자 검수가장 세밀하지만 결과가 잘게 쪼개져 긴 문서에서는 읽기 어렵습니다.

예를 들어 "해지 30일 전"이 "해지 60일 전"으로 바뀐 경우, 라인 단위 비교는 문장 전체를 변경으로 표시하지만 단어 단위 비교는 30일과 60일만 정확히 짚어줍니다.

3. 실제로는 같은데 다르게 나오는 "가짜 차이" 5가지

내용은 같은데 비교 결과에 변경이 잔뜩 표시된다면 눈에 보이지 않는 차이 때문일 가능성이 높습니다.

  • 들여쓰기·탭/스페이스: 로직은 그대로인데 공백 문자만 바뀐 줄이 전부 변경으로 잡힙니다.
  • 줄바꿈 방식(LF/CRLF): Windows와 Linux/macOS 사이를 오간 파일은 모든 줄 끝 문자가 달라서 전체 줄이 다른 줄로 판정됩니다.
  • 줄 끝 공백: 눈에 보이지 않는 후행 공백 한두 칸이 줄 단위 비교를 어긋나게 합니다.
  • 파일 끝 개행: 마지막 줄 뒤의 빈 줄 유무만으로도 차이가 표시될 수 있습니다.
  • 한글 유니코드 정규화(NFC/NFD): 같은 "한"이라도 조합형(자모 분리)으로 저장되면 완성형과 다른 문자열로 판정됩니다. macOS에서 가져온 파일명이나 텍스트에서 가끔 발생합니다.

공백·줄바꿈을 무시하는 옵션이 있다면 먼저 켜서 실질적인 내용 변경만 확인한 뒤, 서식 변경은 별도로 점검하는 두 단계 접근이 효율적입니다.

4. 일치율(%) 수치를 해석할 때의 주의점

많은 비교 도구가 "일치율 97%"처럼 유사도를 보여줍니다. 아래는 LCS를 이용한 대표적인 계산식 예시입니다.

// 라인 단위 LCS 길이 계산 (동적 계획법) function lcsLength(a, b) { const dp = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0)); for (let i = 1; i <= a.length; i++) { for (let j = 1; j <= b.length; j++) { dp[i][j] = a[i - 1] === b[j - 1] ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]); } } return dp[a.length][b.length]; } // 일치율(%) = 2 × LCS / (원본 줄 수 + 수정본 줄 수) × 100

이 수치는 변경의 "양"을 보여줄 뿐 "중요도"는 알려주지 않습니다. 천 줄짜리 문서에서 핵심 조항 한 줄만 바뀌어도 일치율은 99.9%로 나옵니다. 따라서 일치율이 높더라도 하이라이트된 변경 위치는 반드시 직접 확인해야 합니다.

5. 실무 활용 시나리오

  • 계약서·약관 개정본 대조: 단어 단위 비교로 금액, 기간, 조건 변경을 놓치지 않고 확인합니다.
  • 코드 리뷰 전 사전 점검: 수정 전후 코드를 붙여넣어 의도하지 않은 변경이 섞이지 않았는지 확인합니다.
  • 설정 파일 변경 추적: 운영 서버와 개발 서버의 설정 파일을 비교해 환경 간 차이를 찾습니다.
  • 문서 버전 정리: 여러 사람이 수정한 보고서 초안 중 어느 부분이 달라졌는지 빠르게 파악합니다.
