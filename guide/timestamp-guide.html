TIME

Unix Epoch Timestamp 개념과 KST/UTC 시간대 변환 완벽 가이드

1. Unix Epoch Timestamp란 무엇인가?

유닉스 타임스탬프(Unix Timestamp)는 1970년 1월 1일 00:00:00 UTC(협정 세계시)를 기점으로 현재까지 경과한 시간을 '초(Seconds)' 또는 '밀리초(Milliseconds)' 단위의 정수로 나타낸 표기법입니다. 전 세계의 서버와 데이터베이스 간 시간 데이터를 일관되게 동기화하고 연산할 때 사용됩니다.

2. 실무에서 시간 계산 시 주의할 점 (초 vs 밀리초)

백엔드 시스템(Python, PHP, C 언어 등)은 일반적으로 10자리 단위의 '초(Seconds)'를 반환하는 반면, 프론트엔드 자바스크립트의 Date.now()나 Java 시스템은 13자리 단위의 '밀리초(Milliseconds)'를 기본으로 사용합니다. 자릿수를 혼동할 경우 1970년대로 계산되는 오류가 발생하므로 변환 전 반드시 자릿수를 확인해야 합니다.

// 자바스크립트 초/밀리초 단위 타임스탬프 변환 예제 const currentEpochMs = Date.now(); // 13자리 밀리초 const currentEpochSec = Math.floor(currentEpochMs / 1000); // 10자리 초 // 타임스탬프를 한국 시간(KST, UTC+9) 문자열로 변환 const kstDateString = new Date(currentEpochMs).toLocaleString('ko-KR', { timeZone: 'Asia/Seoul' });

3. 무료 온라인 타임스탬프 변환기 활용

복잡한 계산식 없이 10자리 초와 13자리 밀리초 타임스탬프를 한국 표준시(KST) 및 UTC 표준시로 1초 만에 상호 변환할 수 있습니다.
