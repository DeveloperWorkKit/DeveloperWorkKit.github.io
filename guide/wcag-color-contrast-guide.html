웹 접근성(WCAG 2.1) 명도 대비비 기준과 실무 UI 배색 가이드

1. 명도 대비비(Color Contrast Ratio)의 중요성

웹 디자인과 프론트엔드 개발에서 글자색과 배경색의 명도 대비가 부족하면 저시력 사용자뿐만 아니라 야외 직사광선 환경의 모든 사용자가 정보를 읽기 어렵습니다. W3C의 웹 콘텐츠 접근성 지침(WCAG 2.1)은 누구나 텍스트를 또렷하게 인지할 수 있도록 수학적인 명도 대비비 기준을 정의하고 있습니다.

2. WCAG 2.1 핵심 가독성 판정 기준

실무 UI 디자인 및 프론트엔드 개발 시 반드시 준수해야 하는 기준 수치입니다:

  • 일반 본문 텍스트 (18pt / 24px 미만): 최소 4.5 : 1 이상 (AA 등급) / 권장 7.0 : 1 이상 (AAA 등급)
  • 대형 텍스트 (18pt 이상 또는 14pt 볼드 이상): 최소 3.0 : 1 이상 (AA 등급) / 권장 4.5 : 1 이상 (AAA 등급)
  • UI 컴포넌트 및 그래픽 요소 (버튼 테두리, 입력 폼): 최소 3.0 : 1 이상 (AA 등급)
// W3C 상대 휘도(Relative Luminance) 기반 명도 대비비 계산식 Contrast Ratio = (L1 + 0.05) / (L2 + 0.05) * L1: 더 밝은 색상의 상대 휘도 (0.0 ~ 1.0) * L2: 더 어두운 색상의 상대 휘도 (0.0 ~ 1.0) * 결과 범위: 1:1 (동일 색상) ~ 21:1 (순수 블랙 vs 순수 화이트)

3. 실무 UI 3채널 배색 계층 설계 팁

대부분의 모던 웹/앱 UI는 주 텍스트(Primary Title), 보조 텍스트(Secondary Body), 배경색(Background)의 3단 구조로 이루어집니다. 본문 텍스트는 4.5:1(AA) 이상을 확보하고, 핵심 타이틀과 액션 버튼은 7.0:1(AAA) 이상을 유지하는 것이 가장 이상적인 시각 위계를 형성합니다.

4. 무료 온라인 색상 스튜디오 활용

복잡한 휘도 계산 없이 브라우저에서 실시간으로 3채널 배색을 조율하고, WCAG 2.1 명도 대비비를 0.01 단위로 검증하며 디자인 토큰(CSS / Tailwind)을 원클릭 추출할 수 있습니다.
