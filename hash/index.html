HASH UUID & 해시 생성기

개발 테스트용 UUID 식별자 및 안전한 단방향 암호화 해시 생성기입니다.

UUID v4 표준 생성 및 SHA-256, SHA-512 해시 값을 브라우저 내부 Web Crypto API로 계산합니다.

UUID & 해시 생성기 사용 방법 안내:
  1. 좌측에서 생성할 개수(1~50개)를 선택하고 [UUID 생성]을 클릭하여 고유 식별자를 발급받습니다.
  2. 우측에 문자열을 입력하면 SHA-256, SHA-512, SHA-1 암호화 해시가 실시간으로 자동 산출됩니다.
  3. 모든 연산은 클라이언트 사이드에서 즉시 실행되어 입력 데이터가 외부 서버로 전송되지 않습니다.
