STRGET

문자열 추출기

텍스트 뭉치에서 이메일, 전화번호, 패턴 데이터를 1초 만에 추출하고 엑셀 표 형태로 복사합니다.
FILE

폴더 구조 엑셀

로컬 폴더나 ZIP 압축 파일의 계층 구조를 인덴트가 정돈된 엑셀 파일로 출력합니다.
DIFF

텍스트 문서 비교

두 개의 텍스트나 소스 코드 간의 차이점(Diff)을 실시간으로 비교하고 차이점을 시각화합니다.
QR

QR 마스터

원하는 URL 및 텍스트 데이터를 고화질 QR 코드로 즉시 생성하고 다운로드합니다.
