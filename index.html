DWK HUB

DevWorKit

직장인과 개발자의 야근을 줄여주는 무료 IT 생산성 툴킷 세트

STRGET

문자열 추출기

비정형 텍스트에서 이메일, 전화번호 등 특정 패턴 데이터를 정규식으로 추출하여 표 형태로 복사합니다.
COUNTER

글자수 & 바이트 계산기

공백 포함·제외 글자 수와 한글 인코딩 규격(EUC-KR, UTF-8)별 바이트 용량을 실시간으로 측정합니다.
STRCMP

텍스트 문서 비교

두 텍스트 또는 소스코드 간의 차이점(Diff)을 라인 및 단어 단위로 대조하여 변경 사항을 시각화합니다.
MARKDOWN

마크다운 실시간 에디터

LaTeX 수학 수식, Mermaid 다이어그램, 체크리스트, 표 문법을 3단 스크롤 모드로 실시간 확인하고 HTML 코드를 추출합니다.
FSEE

폴더 구조 엑셀

디렉터리 및 ZIP 압축 파일의 계층 구조를 트리 인덴트가 적용된 스프레드시트 형태로 변환합니다.
CODER

Base64 & URL 변환기

UTF-8 기반 Base64 상호 인코딩·디코딩과 URL 파라미터 및 HTML 엔티티 변환을 지원합니다.
BEAUTIFY

코드 뷰티파이어 & 뷰어

HTML, CSS, JavaScript 소스코드를 표준 들여쓰기로 정렬하고 HTML 렌더링 화면을 실시간 미리 봅니다.
JSON

JSON 포맷터 & 검사기

압축되거나 비정형화된 JSON 데이터를 들여쓰기 정렬하고 구문 오류(Syntax Error) 위치를 검증합니다.
TIME

타임스탬프 변환기

초·밀리초 단위 Unix Epoch Timestamp와 한국 표준시(KST), 협정 세계시(UTC)를 상호 변환합니다.
HASH

UUID & 해시 생성기

UUID v4 식별자를 생성하고 SHA-256, SHA-512 등 단방향 암호화 해시값을 계산합니다.
QRM

QR 마스터

URL 및 텍스트 데이터를 벡터 기반 QR 코드로 생성하고 이미지 파일로 내보냅니다.
CRON

크론탭 주기 생성기

리눅스 crontab 스케줄링 표현식을 생성하고 5개 필드 주기를 자연어 해석과 향후 실행 일정으로 계산합니다.
COLOR

웹 색상 스튜디오 & UI 가독성

주 텍스트, 본문, 배경색 3채널의 W3C WCAG 2.1 명도 대비비를 실시간 검증하고 토큰 코드를 생성합니다.
