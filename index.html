Developer Work Kit

직장인과 개발자의 야근을 줄여주는 무료 IT 생산성 툴킷 세트

STRGET

문자열 추출기

텍스트 뭉치에서 이메일, 전화번호, 패턴 데이터를 1초 만에 추출하고 엑셀 표 형태로 복사합니다.
COUNTER

글자수 & 바이트 계산기

공백 포함/제외 글자 수와 EUC-KR(자소서/공공기관), UTF-8 바이트를 실시간으로 정확하게 측정합니다.
CODER

Base64 & URL 변환기

한글(UTF-8) 깨짐 없는 실시간 Base64 인코딩/디코딩 및 URL, HTML 엔티티 변환을 지원합니다.
JSON

JSON 포맷터 & 검사기

엉킨 JSON 데이터를 읽기 쉽게 들여쓰기 정렬하고, 문법 오류 위치를 실시간으로 검사합니다.
FSEE

폴더 구조 엑셀

로컬 폴더나 ZIP 압축 파일의 계층 구조를 인덴트가 정돈된 엑셀 파일로 1초 만에 출력합니다.
STRCMP

텍스트 문서 비교

두 개의 텍스트나 소스 코드 간의 차이점(Diff)을 실시간으로 비교하고 변경 내역을 시각화합니다.
QRM

QR 마스터

원하는 URL 및 텍스트 데이터를 고화질 QR 코드로 즉시 생성하고 PNG 이미지로 다운로드합니다.
