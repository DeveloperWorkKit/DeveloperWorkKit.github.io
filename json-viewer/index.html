JSON JSON 포맷터 & 유효성 검사기

복잡하고 엉킨 JSON 데이터를 보기 쉽게 정렬하고 검사하는 도구입니다.

한 줄로 뭉개진 데이터의 들여쓰기 포맷 정돈, 공백 압축, 문법 오류 실시간 검출을 무료로 제공합니다.

JSON 포맷터 및 검사기 사용 방법 안내:
  1. 좌측 입력창에 검사할 JSON 데이터를 직접 입력하거나 [클립보드 불러오기] 또는 [샘플 불러오기]를 클릭합니다.
  2. 상단의 [2칸 정렬] 또는 [4칸 정렬] 버튼을 클릭하면 읽기 편한 계단식 들여쓰기 형태로 자동 정렬됩니다.
  3. 쉼표(,)나 따옴표("") 누락 등 문법 오류가 있을 경우 상단 알림 바에 에러 원인과 발생 위치가 실시간으로 안내됩니다.
  4. 데이터 전송용 압축이 필요할 때는 [1줄 압축 (Minify)], 개발 모델이 필요할 때는 [TypeScript 변환]을 활용할 수 있습니다.
