JSON JSON 포맷터 & 유효성 검사기

복잡하고 엉킨 JSON 데이터를 보기 쉽게 정렬하고 검사하는 도구입니다.

한 줄로 뭉개진 데이터의 들여쓰기 포맷 정돈, 공백 압축, 문법 오류 실시간 검출을 무료로 제공합니다.

JSON 포맷터 및 검사기 사용 방법 안내:
  1. 좌측 입력창에 JSON 데이터를 입력하거나 상단의 [샘플 불러오기]를 클릭합니다.
  2. 좌측 상단의 파란색 [정렬 실행 ▶] 버튼을 누르면 우측 화면에 읽기 좋은 들여쓰기 형태로 변환됩니다.
  3. 상단 옵션 바에서 4칸 정렬, 1줄 압축(Minify), TypeScript 변환 등 원하는 모드로 바로 실행할 수도 있습니다.
  4. 에디터 내에서 Ctrl + Z (실행 취소) 및 Ctrl + Y (다시 실행)를 완벽하게 지원합니다.
