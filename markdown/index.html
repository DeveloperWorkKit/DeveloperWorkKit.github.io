MARKDOWN 마크다운 실시간 에디터

작성한 마크다운 문서를 실시간으로 확인하고 검증하는 도구입니다.

수학 수식, 다이어그램, 체크리스트, 콜아웃 문법을 3단 스크롤 모드로 실시간 확인하고 깔끔한 HTML 코드를 즉시 추출합니다.

마크다운 실시간 에디터 사용 방법 안내:
  1. 좌측 입력창에 마크다운 문서를 작성하면 우측 뷰어에 실시간으로 서식이 적용되어 렌더링됩니다.
  2. 상단 템플릿 버튼([다이어그램], [수학 수식], [알림 콜아웃] 등)을 클릭하여 커서 위치에 예제 코드를 바로 삽입할 수 있습니다.
  3. 우측 상단에서 [동시 휠 스크롤], [스마트 추적], [독립 스크롤] 중 원하는 동기화 모드를 자유롭게 전환할 수 있습니다.
  4. 작성이 완료되면 상단의 [⚡ HTML 복사] 또는 [💾 .md 저장] 버튼을 눌러 결과물을 내보냅니다.
