STRGET 문자열 추출기

긴 텍스트에서 원하는 패턴의 데이터만 고속으로 추출하는 도구입니다.

이메일, 전화번호, 숫자, 날짜 및 커스텀 정규식 패턴을 실시간으로 매칭하고 엑셀 표로 복사합니다.

문자열 추출기 사용 방법 안내:
  1. 우측 본문 입력창에 데이터를 입력하거나 [샘플 불러오기]를 클릭하여 테스트 데이터를 로드합니다.
  2. 좌측에서 [이메일 매칭], [전화번호], [숫자] 등 원하는 추출 프리셋 버튼을 클릭합니다.
  3. 본문에서 실시간으로 형광펜 강조된 단어를 확인하고, 하단의 [엑셀/CSV용 표 형태로 복사]를 눌러 클립보드에 저장합니다.
  4. 원하는 특정 서식이 있는 경우 [사용자 지정 패턴 입력]을 통해 정규식을 직접 작성하고 브라우저에 영구 저장할 수 있습니다.
본문 데이터 입력
선택한 샘플:
매칭 데이터: 0건
본문 글자를 마우스로 드래그하면 동일한 패턴을 자동으로 찾아주며, 형광펜 글자를 클릭하면 해당 순번으로 바로 연동됩니다.
